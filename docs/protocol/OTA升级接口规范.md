# 通讯接口定义
## 接口列表

| 序号 | 接口名称 | 内容 |
| --- | --- | --- |
| 1 | 更新接口 | 请求TMS更新 ：POS机请求TMS更新响应POS：TMS响应POS机 |
| 2 | 下载接口 | 请求TMS下载：POS机请求TMS下载响应POS：TMS响应POS机 |
| 3 | 通知接口 | 安装完成通知：POS机安装成功通知TMSTMS响应：TMS响应POS机 |

## 终端状态设置
### 请求报文

| 字段名称 | 字段含义 | 字段类型 | 字段长度 | 字段说明 |
| --- | --- | --- | --- | --- |
| msgLength | 报文长度 | String | 2 | 必填 |
| orderCode | 命令码 | String | 2 | 13 |
| posCATI | POS终端号 | String | 8 | 不足，右边补空格 |
| posSN | POS序列号 | String | 32 | 不足，右边补空格 |
| Term_Status | 终端状态 | String | 16 | 不足，右边不空格 |
| Random | 随机数 | String | 16 | 必填 |
| TermStatus_Sign | 签名 | String | 512 | 不足，左边补0 |
| lrc | 校验位 | Byte | 1 | 必填 |

终端状态密文的计算方式：数据为hex格式
数据明文格式为：SN_Len(1)+SN+终端状态(8)+随机数(8)+99应答码内的随机数（8）
对第1步的数据进行sha256计算
用终端Term_SK对第2步的HASH值进行PKCS1签名。
将签名的结果转为ASCII码格式
### 响应报文

| 字段名称 | 字段含义 | 字段类型 | 字段长度 | 字段说明 |
| --- | --- | --- | --- | --- |
| msgLength | 报文长度 | String | 2 | 必填 |
| responseCode | 响应码 | String | 2 | 必填 |
| TermStatus_RSA | 终端状态密文 | String | 512 | 不足，左边补0 |
| lrc | 校验位 | Byte | 1 | 必填 |

终端状态密文计算方式：
数据明文格式为：SN_Len(1)+SN+终端状态(8)+终端请求的随机数(8)+99应答码内的随机数（8）
用终端的Term_PK,对第1步的数据进行PKCS1加密。
将加密结果转为ASCII码

# 版本号规则
## 软件版本
V + 当前日期 + 编号（2位数字）如：V2011022801
当前日期的格式为：yyyyMMdd（如：20110212）
## 参数版本
V + 当前日期 + 编号（2位数字）如：V2011022801
当前日期的格式为：yyyyMMdd（如：20110212）
# 报文格式及校验位
## 报文格式
GRPS和网线请求的报文格式：长度+命令吗+报文信息+lrc
## 校验位
校验位是校验的命令吗+报文信息
